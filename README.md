# 影之刃零 · 猫娘陪玩

> 让宿主猫娘陪你闯《Phantom Blade Zero / 影之刃零》。

N.E.K.O 插件 · 游戏状态感知 · 江湖知识库 · 跨会话记忆 · 影帐面板

## 这是什么

`neko_pbz` 把《影之刃零》的当前局面、任务推进、装备状态和游戏知识交给宿主里的猫娘，
让她能在探索、战斗、死亡、卡关和日常闲聊中给出贴合场面的回应。

猫娘使用宿主当前人设说话：称呼、语气、口癖、主动程度和 TTS 都由宿主配置决定。
插件负责事实与记忆，不替代人设，也不把固定台词塞进聊天窗。

## 核心能力

- **实时局面**：读取区域、生命、杀气、战斗状态、前方敌人、Boss、铃铛和当前任务。
- **当前装备**：读取主/副武器、影之武装、饰品和药瓶快捷栏，不读取背包持有量。
- **战前情报**：根据 Boss、区域和当前装备，从已验证内容中随机给出 1~3 条提示。
- **任务陪跑**：查询任务下一步、目标区域、前置条件、失败提醒和奖励。
- **探索知识**：检索铃铛、收集物、NPC、路线、物品获取位置、Boss 与首领组。
- **即时陪玩**：游戏内 F12 或面板一键让猫娘看局面、任务、Boss 或本局复盘。
- **自然语言控制**：直接让猫娘静默、继续、关字幕、关语音、切剧透或暂停即时陪玩。
- **状态校准**：面板明确显示生命、杀气、敌人、装备、任务和桥接字段是否读取成功。
- **跨会话记忆**：记录 Boss 尝试、死亡、最佳进度、偏好、约定和共同经历。
- **本局目标**：设置、完成或清除当前目标，并纳入会话摘要与即时陪玩。
- **死亡前快照**：保存生命、杀气、Boss、敌人和装备，用于具体复盘。
- **宿主语音**：通过宿主生成最终回复与 TTS，再把同一段文字写入游戏内字幕。
- **视觉兜底**：F11 截取游戏窗口，交给宿主视觉模型判断画面，不持续录屏。
- **独立灵犀**：可配置独立 LLM；未配置时自动回退宿主 LLM，失败不阻塞游戏。

## 快速开始

1. 在 N.E.K.O 插件管理中导入并启用 `neko_pbz`。
2. 运行插件部署脚本，安装游戏侧 Mod：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\deploy.ps1
```

部署前请关闭《影之刃零》和 N.E.K.O。脚本检测到运行中进程会停止并提示；
自动化场景确认风险后可显式添加 `-Force`，但运行中的游戏仍需重启后才会加载新 Mod。

3. 启动《影之刃零》，确认 `PBZModLoader` 与 `PBZNekoCompanion` 已加载。
4. 打开“影帐”面板，确认连接状态与游戏状态正常更新。
5. 在 N.E.K.O 聊天里直接向猫娘提问或让她陪玩。

## 影帐面板

面板采用水墨、朱砂、戏曲花窗与青绿山水组合的武侠视觉，分七个区域：

- **战局**：区域、生命、杀气、战斗状态、当前装备、本局目标、Boss 与最近一句。
- **侦察**：前向罗盘、敌人方位与距离、Boss 情报、铃铛、即时陪玩和画面侦察。
- **交锋**：Boss 尝试次数、死亡次数、最佳进度、最近死亡快照和事件流。
- **忆卷**：跨会话记忆、约定、偏好、统计与导出。
- **百晓**：Boss、任务、路线、收集物、NPC、物品、装备和玩法库检索。
- **灵犀**：独立 LLM 配置、连接测试、调用次数和 Token 统计。
- **调息**：TTS、字幕、主动说话、剧透等级、建议条数、静默和界面风格。

面板提供水墨卷轴、戏台花窗、江湖战报、青绿山水四种结构风格，
可叠加墨夜、宣纸、赤影、青锋辅助配色，并支持密度、缩放和减少动效。

侦察数据在前台且面板可见时每 1.5 秒刷新，也可以手动重新扫描。

## 游戏内热键

| 热键 | 功能 |
|---|---|
| `F10` | 显示或隐藏猫娘字幕 |
| `F11` | 截取当前游戏画面并交给宿主视觉模型 |
| `F12` | 请求一次即时陪玩提醒 |

## 即时陪玩

即时陪玩用于“现在就想听猫娘说一句”的场景，不依赖固定帮助模板。插件会整理当前局面，
再交给宿主当前人设生成回复与 TTS，最终文本同步写入游戏字幕。

| 焦点 | 面板入口 | 回应内容 |
|---|---|---|
| `brief` | 看当前局面 | 生命、杀气、战斗状态、Boss 与眼前最值得注意的一件事 |
| `quest` | 看任务 | 当前任务进度，并结合知识库指出优先步骤 |
| `boss` | 看 Boss | 当前 Boss、首领组、短攻略与 1~3 条相关建议 |
| `review` | 复盘本局 | 死亡次数、Boss 战绩、去过的区域与最近事件 |

游戏内按 `F12` 等同“看当前局面”。面板按钮位于“侦察 → 即时陪玩”。
请求最多每 3 秒一次，避免连续按键打断猫娘；可在“调息”关闭该功能。

聊天中也可以自然地说“看看我现在该怎么打”“帮我复盘这一局”，
由 `pbz_assist` 工具选择对应焦点。

“当前任务”卡片上方可以设置本局目标，例如“推进主线”“收集三件武器”。
目标完成后会保留状态；复盘时会同时参考最近一次死亡前的生命、杀气、Boss 血量和附近敌人。

## 陪玩控制

可以直接用聊天控制插件，不需要翻设置页：

- “安静 30 分钟”“先别主动说话”“解除静默”；
- “关掉游戏字幕”“打开宿主语音”；
- “以后别剧透第三章”“恢复到区域级提示”；
- “暂停即时陪玩”“允许 F12 提醒”。

控制只保存插件配置，不代表固定回复文案；确认语句仍由宿主当前猫娘人设生成。

“侦察 → 状态校准”会列出关键读取项。缺失项不会猜测补齐，也可以导出报告到
`data/diagnostics/latest.json`。

## 知识库

知识库由 JSON 种子导入 SQLite，入口、检索、筛选和 LLM 工具均读取同一份数据。
当前包含 1446 个去重实体，覆盖：

- 61 个 Boss 与首领组；
- 72 条任务及分步目标；
- 87 条探索路线；
- 534 个收集物；
- 171 个铃铛；
- 279 个道具；
- 66 个饰品、17 个药瓶、27 把主武器、25 个影之武装；
- 15 个 NPC、13 个区域、玩法库与战斗机制。

每种实体保留来源、剧透等级、置信度和可核验事实。玩家纠正保存在
`data/knowledge/corrections/`，种子升级后会重新应用。

百晓页支持“记录实测纠错”：保存实体字段、玩家实测值、原值、测试备注和时间。
有玩家证据的条目会显示“玩家实测”，知识重载不会覆盖。聊天里也可以要求
“记住这个 Boss 的实际招式”或“更正这条任务资料”。

知识数据位于 `data/knowledge/`，来源说明见
[sources.json](data/knowledge/sources.json)。

## 数据与隐私

插件数据统一保存在自己的 `data/`：

```text
data/
├─ config/
│  ├─ general.json
│  ├─ llm.json
│  └─ ui.json
├─ memory/
│  ├─ _global/profile.json
│  ├─ <存档>/
│  │  ├─ save.json
│  │  ├─ bosses.json
│  │  ├─ facts.json
│  │  ├─ preferences.json
│  │  ├─ promises.json
│  │  ├─ goal.json
│  │  ├─ last_death.json
│  │  └─ sessions/*.json
│  └─ exports/*.json
└─ knowledge/
   ├─ seed*.json
   ├─ pbz_knowledge.db
   └─ corrections/*.json
```

- API Key 只写入本机 `data/config/llm.json`，不会回传到前端；Windows 优先使用
  DPAPI 保护，受限环境使用非明文本地编码。
- 截图只来自《影之刃零》窗口，不截桌面，不做持续录屏。
- 不读取背包、仓库和材料数量。
- 不修改游戏存档、数值或输入。

## 配置

### 基础配置

`data/config/general.json` 保存桥接目录、轮询间隔、主动说话、建议条数、
剧透等级、静默时间、TTS 与字幕开关。

### 独立 LLM

“灵犀”支持 OpenAI 兼容、OpenAI、Anthropic 与 Gemini 接口。
配置 Provider、Model、API Key、Base URL、超时和每分钟调用上限。

调用优先级：

1. 已启用独立 LLM 且配置完整；
2. 回退宿主主体 LLM；
3. 两者均不可用时使用本地规则生成记忆摘要。

### 界面

`data/config/ui.json` 保存结构风格、辅助配色、密度、缩放、动效、
雷达与灵犀摘要开关。

## 安装文件

部署脚本会更新：

1. 两个 N.E.K.O 活动插件目录；
2. `PBZModLoader` 的 `pbz-neko-companion`；
3. UE4SS 的 `PBZNekoCompanion`；
4. `ProjectPBZ\Saved\NekoBridge` 桥接目录；
5. `generated-config.js` 与 `mods.txt` 中的启用项。

脚本只更新本插件自己的文件，不修改宿主源码、游戏 Pak 或存档。

## 排障

### 面板显示未连接

确认桥接目录存在以下文件并持续更新时间：

```text
ProjectPBZ\Saved\NekoBridge\state.json
ProjectPBZ\Saved\NekoBridge\heartbeat.json
```

游戏侧使用 EasyCsv 目录槽位时，实际文件为：

```text
ProjectPBZ\Saved\NekoBridge\state\New_CSV.csv
ProjectPBZ\Saved\NekoBridge\mod_status\New_CSV.csv
ProjectPBZ\Saved\NekoBridge\game_heartbeat\New_CSV.csv
```

### 有状态但没有语音

检查宿主 `push_message` 是否可用、TTS 是否启用，以及当前是否处于静默时间。

### 游戏内没有字幕

确认 UE4SS 的 `PBZNekoCompanion` 已启用，且桥接目录可写。

### 读不到生命、敌人或装备

打开面板“侦察”页查看能力状态，并运行：

```powershell
python .\scripts\probe_report.py
```

无法确认的字段保持为空，插件不会猜测，也不会用背包数据补齐。

### 画面侦察失败

确认游戏处于前台、窗口未最小化、画面未全黑，并检查宿主是否支持视觉模型。
