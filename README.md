# 影之刃零 · 猫娘陪玩

让 N.E.K.O 中的猫娘读取《影之刃零》的当前局面，陪你探索、战斗、查任务和复盘。

## 功能

- 读取生命、杀气、区域、战斗状态、敌人、Boss、铃铛和当前任务。
- 读取当前主副武器、影之武装、饰品和药瓶，不读取背包数量。
- 结合任务、Boss 和装备知识给出提示，并记住 Boss 尝试、卡关和偏好。
- 使用宿主当前猫娘人设生成聊天、语音和游戏字幕。
- 可选独立 LLM；未配置时自动使用宿主 LLM。

## 安装

1. 从 N.E.K.O 插件市场安装并启用 `neko_pbz`。
2. 关闭《影之刃零》，打开“影帐 → 调息 → 游戏侧组件”。
3. 点击“自动检测”，再点击“一键安装 UE4SS + Mod”。首次安装会下载并校验
   UE4SS 运行时。
4. 启动游戏和 N.E.K.O，确认面板显示已连接。

已有 UE4SS 和第三方 Mod 无需卸载。安装器只补齐本插件文件，修改前会备份。
市场包不携带可执行文件，UE4SS 运行时从固定 Release 下载并校验 SHA-256。
自动检测失败时可查看 [游戏侧安装说明](docs/ONE-CLICK-INSTALL.md)。

## 影帐面板

- **战局**：生命、杀气、区域、装备、Boss 和当前目标。
- **侦察**：敌人方向、任务、Boss 情报、即时陪玩和画面识别。
- **交锋**：Boss 战绩、死亡记录、最近事件和本局复盘。
- **忆卷**：长期记忆、约定、偏好和共同经历。
- **百晓**：Boss、任务、路线、收集物、NPC、物品和装备知识。
- **灵犀 / 调息**：独立 LLM、语音、字幕、主动说话、剧透和静默设置。

`F10` 显示或隐藏字幕，`F11` 识别当前画面，`F12` 请求一次即时陪玩。

## 数据与边界

- 不读取背包、仓库或材料数量。
- 不修改游戏存档、数值或输入。
- 截图只截取《影之刃零》窗口，不持续录屏。
- 配置、记忆和知识数据保存在插件自己的 `data/` 目录。
- 聊天是主通道；普通事件排队，死亡、低血和 Boss 阶段等紧急事件可以插队。

完整权限说明见 [宿主接入与权限](docs/HOST-INTEGRATION.md)，界面上可直接打开
[使用指南](docs/ui/guide.md)。

## 常见问题

- **面板未连接**：确认游戏侧组件已安装，然后重启游戏和 N.E.K.O。
- **生命或装备为空**：在“侦察 → 状态校准”查看具体读取失败项。
- **没有语音**：检查宿主 TTS 是否开启，以及插件是否处于静默时间。
- **没有游戏字幕**：确认 `PBZNekoCompanion` 已启用并重启游戏。
