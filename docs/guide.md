# 影之刃零猫娘陪玩

## 这是什么

让宿主当前猫娘陪主人玩《影之刃零》：

- 读当前局面：生命、杀气、战斗状态、当前武器/影之武装/饰品；
- 读世界：区域、Boss、前方敌人、铃铛、任务；
- 跨会话记忆：上次卡关、Boss 尝试、常用装备、偏好、约定；
- 知识库：Boss、小怪、铃铛、武器、影之武装、铸魂；
- Boss 前从已验证建议池随机给 1~3 条。

## 边界

- 不读取背包、仓库、材料数量；
- 不改存档、不改数值、不注入操作；
- 台词与 TTS 都由宿主当前猫娘人设负责；
- 插件只提供事实、记忆与提示。

## 使用

1. 启用插件；
2. 启动游戏并确认 `PBZModLoader` 与 `PBZNekoCompanion` 已加载；
3. 打开面板确认“已连接”；
4. 在宿主聊天里直接问“我现在什么状态”“前面有什么怪”“这个 Boss 怎么打”。

## 键盘

- F10：显示/隐藏游戏内字幕。

## 排障

- 面板显示未连接：检查桥接目录下是否有 `state.json` 与 `heartbeat.json`；
- 有状态但没台词：确认宿主 `push_message` 可用、语音开关打开；
- 游戏内没字幕：确认 UE4SS 的 `PBZNekoCompanion` 已启用。
