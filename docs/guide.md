# 影之刃零猫娘陪玩

## 这是什么

让宿主当前猫娘陪主人玩《影之刃零》：

- 读当前局面：生命、杀气、战斗状态、当前武器/影之武装/饰品；
- 读世界：区域、Boss、前方敌人、铃铛、任务；
- 跨会话记忆：上次卡关、Boss 尝试、常用装备、偏好、约定；
- 知识库：Boss、任务、路线、铃铛、收集物、NPC、物品、武器、影之武装与铸魂；
- Boss 前从已验证建议池随机给 1~3 条。

## 边界

- 不读取背包、仓库、材料数量；
- 不改存档、不改数值、不注入操作；
- 台词与 TTS 都由宿主当前猫娘人设负责；
- 插件只提供事实、记忆与提示。

## 使用

1. 启用插件；
2. 启动游戏并确认 `PBZModLoader` 与 `PBZNekoCompanion` 已加载；
3. 打开面板确认“已连接”；
4. 在宿主聊天里直接问“我现在什么状态”“前面有什么怪”“这个 Boss 怎么打”。
5. 查任务时可以直接说“白山秘闻下一步去哪”，查物品时可以说“红妆鬼斩在哪拿”。
6. 想立即听猫娘结合当前局面接一句，可以按 `F12`，或打开“侦察 → 即时陪玩”。

## 本局目标与复盘

- 在“当前任务”上方输入本局目标，点“定目标”保存；
- 完成后点“完成”，目标状态会写入当前存档；
- “交锋”页显示最近一次死亡前的生命、杀气、Boss 血量和附近目标；
- 说“复盘本局”时，猫娘会参考目标、死亡快照、Boss 历史和最近事件。

## 陪玩控制

可以在聊天中直接说：

- “安静 30 分钟”“先别主动说话”“解除静默”；
- “关掉游戏字幕”“打开宿主语音”；
- “暂停即时陪玩”“允许 F12 提醒”；
- “切到只讲眼前的剧透等级”。

“侦察 → 状态校准”会显示生命、杀气、敌人、装备、任务和桥接是否读取成功。
缺失的字段会明确提示，也可以导出到 `data/diagnostics/latest.json`。

## 知识纠错

- 在百晓搜索实体后点“记录实测纠错”；
- 填写字段、实测值和测试条件；
- “玩家实测”记录会保留旧值，并在种子重载后恢复；
- 也可以直接让猫娘“记住这个 Boss 的实际招式”或“更正任务资料”。

## 即时陪玩

- 看当前局面：综合生命、杀气、战斗状态、Boss 和最近事件；
- 看任务：读取当前任务进度，并补充任务知识里的下一步；
- 看 Boss：补充当前 Boss 的首领组、短攻略和已验证建议；
- 复盘本局：汇总死亡、Boss 战绩、区域和最近事件。

回复由宿主当前猫娘人设生成，不使用固定台词。连续请求有 3 秒冷却，
可在“调息”关闭。

## 事件如何进入对话

插件事件默认采用 `ai_behavior="respond"`、`visibility=[]`：

- 当前局面、装备、任务和事件要求会作为隐藏上下文交给宿主 LLM；
- 宿主触发一次猫娘回复并正常显示这一条回复；
- “影之刃零陪玩事件”“当前事实”“要求”等调试文本不会原样进入近对话窗口。

其他输出边界：

- 常驻场景上下文使用 `ai_behavior="read"`：只让 LLM 看见，不主动回复；
- 明确的系统通知才使用 `ai_behavior="blind"`：只显示，不进入 LLM；
- “调息”中的“调试：显示事件提示词”默认关闭。只有排查注入问题时才建议打开，
  打开后会看到事件事实块和猫娘回复两条内容。

相同事件在 3 秒内被结构化事件与桥接事件重复送入时只保留一次，避免同一局面
排队触发两条回复。

## 闲聊与事件优先级

聊天是主通道，游戏事件是辅助信息：

- 主人刚聊过天时，普通事件和重要事件只进入队列，不抢当前对话；
- 默认闲聊保护窗口为 20 秒，可在“调息”中调整为 0~120 秒；
- `death`、`respawn`、`critical_hp`、`boss_phase`、`victory` 属于紧急事件，
  可以插队，并可在普通事件回复尚未完成时替换它；
- 主动说话关闭时，普通事件仍只记录，不触发回复；
- 手动静默优先于所有事件，包括紧急事件；
- 切场、菜单和过场期间不触发事件回复。

重要事件在队列中最多保留 60 秒，普通探索事件保留 12 秒，避免长时间聊天后
突然播报已经过时的内容。

## 键盘

- F10：显示/隐藏游戏内字幕。
- F11：截取当前游戏画面并交给宿主视觉模型。
- F12：请求一次即时陪玩提醒。

## 排障

- 面板显示未连接：检查桥接目录下是否有 `state.json` 与 `heartbeat.json`；
- 有状态但没台词：确认宿主 `push_message` 可用、语音开关打开；
- 游戏内没字幕：确认 UE4SS 的 `PBZNekoCompanion` 已启用。
- 读不到生命、敌人或装备：打开“侦察”页查看能力状态，并运行
  `python .\scripts\probe_report.py`。
- 画面侦察失败：确认游戏位于前台、窗口未最小化，且宿主视觉模型可用。
