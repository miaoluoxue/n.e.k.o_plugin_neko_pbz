# 影之刃零 · 猫娘陪玩使用指南

让宿主猫娘结合当前局面、任务、Boss 与跨会话记忆，陪你探索《影之刃零》。

## 快速开始

1. 安装并启用 `neko_pbz`。
2. 关闭《影之刃零》，打开“影帐 → 调息 → 游戏侧组件”。
3. 点击“自动检测”，再点击“一键安装 UE4SS + Mod”。首次安装需要联网下载
   UE4SS 运行时。
4. 启动游戏和 N.E.K.O，打开面板确认已连接。
5. 在聊天里直接问猫娘，或按 `F12` 让她看一次当前局面。

已安装其他 UE4SS Mod 时无需卸载。安装器只补齐本插件文件，并在修改前备份。

## 常用交互

- “我现在多少血、杀气还剩多少？”
- “前面有什么怪？”
- “这个 Boss 怎么打？”
- “当前任务下一步去哪？”
- “帮我复盘刚才为什么没过。”
- “安静 30 分钟”“先别主动说话”“解除静默”。

猫娘使用宿主当前人设生成回复和语音，插件不写死台词。

## 陪玩设置

“调息”可调整主动说话、字幕、宿主语音、剧透等级、建议条数和静默时间。
“灵犀”可配置独立 LLM；不配置时使用宿主当前 LLM。

`F10` 显示或隐藏游戏字幕，`F11` 交给宿主识别当前画面，`F12` 请求即时陪玩。

## 常见问题

- **面板未连接**：确认游戏侧组件已安装，并重启游戏与 N.E.K.O。
- **没有生命或装备数据**：先在“侦察 → 状态校准”查看哪一项读取失败。
- **猫娘不主动说话**：检查是否处于静默时间，或关闭了主动陪玩。
- **没有游戏字幕**：确认 `PBZNekoCompanion` 已启用，再重启游戏。
