# 版本记录

## 未发布

### 修复

- **当前装备空槽**：停止在角色组件上猜测装备字段，改从运行时确认的
  `PBZBackPackSubsystem` 读取 `MainWeapons`、`ShaqiWeapons`、
  `AssemblyAccessory`、`TopMedicineID` 和 `BottomMedicineID`。
- **饰品库存与装配区分**：`Accessories` 是已获得饰品总表，改读六槽
  `AssemblyAccessory`，避免把 39 件库存误报成当前装备。
- **装备名称与槽位**：通过主武器、影之武装、饰品、药瓶数据表解析名称和等级，
  同时标记当前主武器与当前影之武装槽；仍不读取背包数量和材料。
- **主副武器重复显示**：面板与陪玩上下文按物品 ID 去重，不再把同一件武器
  同时显示为“主武器”和“副武器”。
- **装备强化等级**：武器读取 `MainWeaponInfos.WeaponLevel` 和
  `ShaqiWeaponInfos.ShaChiWeaponLevel`，饰品与药瓶读取各自实例信息的
  `CurrentLevel`。面板不再把已强化装备错误显示为 `+0`。
- **事件重复对话**：游戏事件默认改为 `visibility=[] + ai_behavior="respond"`，
  事实块只注入宿主 LLM，聊天窗口只显示猫娘最终回复。新增默认关闭的调试开关，
  可显式查看发给 LLM 的事件提示词。
- **同源事件去重**：结构化事件和桥接事件在 3 秒内内容相同只入队一次，
  避免同一装备/战斗变化触发两轮回复。
- **多角色推送目标**：按宿主 SDK 的优先级解析 `_current_lanlan`、
  宿主上下文和 `NEKO_TARGET_LANLAN` 等环境变量，避免多猫娘会话中推送被静默丢弃。
- **闲聊优先调度**：通过宿主 `@message(source="chat")` 感知主人聊天，
  默认 20 秒保护窗口内普通与重要事件排队；死亡、复活、低血、Boss 阶段和胜利
  等紧急事件可插队并替换尚未完成的普通事件回复。
- **宿主接入与权限文档**：明确 UI surface 权限、宿主能力、条件能力、操作系统
  访问范围、一键安装写入边界和最小授权配置；关闭未使用的宿主 Store。

### 新增

- **插件内一键安装**：UE4SS、PBZModLoader 代理和游戏侧 Mod 随宿主插件
  统一发布，不再生成独立游戏 ZIP 或插件 ZIP。面板“调息 → 游戏侧组件”
  提供自动检测与一键安装。
- **增量安全安装**：只在 UE4SS 缺失时安装核心文件；已有 UE4SS 和其他
  Lua/PuerTS Mod 不覆盖、不删除。配置采用追加式合并，并在修改前备份。
- **路径自动匹配**：从上次选择、Windows 注册表、Steam
  `libraryfolders.vdf`、逻辑磁盘常见布局和游戏目录结构逐级检测，不写死盘符；
  代理 DLL 或 UE4SS 存在版本冲突时停止安装。
- **vendor 运行时快照**：通过白名单同步脚本保存 UE4SS 核心、签名、布局
  配置和内置依赖，不收入用户现有的第三方 Mod。

## v0.2.0

**主题**：可信状态、控制闭环与长期陪伴。

### 新增

- **自然语言控制**：支持通过聊天调整静默、主动说话、字幕、语音、即时陪玩和剧透等级。
- **状态校准面板**：显示生命、杀气、区域、敌人、装备、任务和桥接的可读状态，
  支持导出 `data/diagnostics/latest.json`。
- **本局目标**：面板可设置、完成或清除当前目标，并进入跨会话摘要。
- **死亡前快照**：保存生命、杀气、Boss、敌人和当前装备，复盘时不再只依据死亡次数。
- **玩家实测纠错**：记录实体、字段、原值、实测值、时间和备注；重载种子后继续生效。
- **百晓维护入口**：搜索结果可直接纠错，并新增玩家实测与纠错数量统计。
- **状态字段兼容**：补充铃铛真实名称、任务描述/任务名和 Boss 阶段字段探测。
- **事件队列治理**：过期低优先级事件自动丢弃，P0 事件优先处理。
- **密钥保护**：Windows 上优先使用 DPAPI 保存独立 LLM Key，不写入明文。
- **自动发布校验**：新增资产校验脚本与 GitHub Actions CI。

### 修复

- **面板无数据**：游戏启动早期字幕 `AddWidget` 失败不再终止状态采样；
  Overlay 改为延迟重试，`state.json` 与 `mod_status.json` 独立写入。
- **EasyCsv 桥接路径**：修正 `SaveStringToFile` 第二参数必须为目录的问题；
  状态、Mod 状态和游戏心跳改为独立 EasyCsv 槽位，Python 端兼容目录读取。
- **EasyCsv UTF-16 解析**：识别 `FF FE` BOM 并自动按 UTF-16 解码，
  修复 `mod_status` 可读但较大的 `state` 始终为空的问题。
- **安全模式**：默认关闭游戏内 UMG 字幕与全场景敌人扫描，以 1 秒频率先稳定传输生命、
  地图、任务、装备等低风险字段；游戏内字幕改为后续显式开启。
- **动态 World 解析**：不再缓存 MainStart 时的空上下文，每帧重新获取 World、
  PlayerController 和本地角色。
- **桥接路径自动发现**：识别 `%LOCALAPPDATA%\ProjectPBZ\Saved\NekoBridge`，
  按最新游戏状态文件选择真实桥接目录。
- **生命/杀气读取**：从角色的 `AttributeSetBase` 读取 `Health`、`Health_Max`
  和杀气属性，修复面板生命、杀气长期显示 `--`。

## v0.1.1

**主题**：即时陪玩与情境化互动。

### 新增

- **游戏内即时陪玩**：按 `F12` 向插件提交一次情境请求，由宿主当前猫娘人设生成回复与 TTS，
  并把同一段文本写入游戏字幕。
- **四类互动焦点**：支持 `brief` 当前局面、`quest` 当前任务、`boss` Boss 情报和
  `review` 本局复盘。面板“侦察 → 即时陪玩”提供四个对应按钮。
- **任务陪跑上下文**：任务焦点会读取当前任务名称、任务进度和知识库步骤，提醒时只强调眼前一步。
- **Boss 情境提醒**：Boss 焦点会补充首领组、短攻略和已验证的 1~3 条建议。
- **本局复盘**：汇总死亡次数、Boss 击败数、去过的区域、Boss 历史与最近事件。
- **聊天工具**：新增 `pbz_assist`，用户可直接让猫娘看局面或复盘。
- **开关与冷却**：可在“调息”关闭即时陪玩；默认请求冷却 3 秒，避免打断上一条回复。

### 升级注意

- 需要重新部署游戏侧 Lua Mod，`F12` 才可用。
- 只使用插件自己的桥接文件与宿主对话能力，不依赖其他插件。
